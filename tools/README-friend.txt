HALLWAY

Unzip anywhere and run hallway.exe. Needs a Vulkan-capable GPU (any GPU from
the last ~8 years). Windows SmartScreen may warn because the exe is unsigned -
"More info" > "Run anyway".

WASD    walk          SHIFT   run
mouse   look          ESC     free / capture the mouse
TAB     switch between ASCII and normal graphics

What you're looking at: one hallway closed at both ends, a doorway each side
into two identical empty rooms with big skylights. All the light is real -
a sun through the skylights, bounced around by the engine. The ASCII mode
just reads the finished frame and replaces each 8x16 pixel cell with a
character of matching brightness.
